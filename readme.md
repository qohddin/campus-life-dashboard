📊 캠퍼스 라이프 데이터 분석 대시보드

본 프로젝트는 파이썬(Python)과 Streamlit을 활용하여 campus_life.csv 데이터를 분석하고 시각화하는 인터랙티브 웹 대시보드입니다. 데이터 분석을 처음 접하는 비전공자 1학년 과정에 맞추어 복잡한 라이브러리나 클래스(class)를 배제하고 직관적인 기초 문법 위주로 작성되었습니다.

📌 주요 기능

데이터 업로드 및 전처리:

CSV 파일을 업로드하여 원본 데이터를 확인합니다.

결측치 및 '모름' 응답을 자동 제외하고 제외된 건수를 표시합니다.

학과 필터링 연동:

사이드바에서 선택한 학과에 맞추어 평균 만족도 및 모든 하단 그래프가 즉각적으로 업데이트됩니다.

생활 습관 비교 (막대그래프):

선택된 학과 학생들과 전체 학생들의 평균 통학시간, 공부시간, 스마트폰 사용시간, 수면시간을 비교합니다.

만족도 상관관계 (산점도):

공부시간, 수면시간, 스마트폰 사용시간과 학교생활 만족도 간의 관계를 시각화합니다.

한 줄 의견 텍스트 분석:

기초적인 문자열 처리(count(), re)를 활용하여 의견 내 긍정/부정 단어 등장 횟수를 카운트합니다.

가장 많이 등장한 상위 10개 단어를 추출하여 막대그래프로 시각화합니다.

🚀 실행 방법

1. 필수 라이브러리 설치

프로젝트 실행을 위해 먼저 필요한 파이썬 패키지들을 설치해야 합니다. 터미널(Terminal) 창을 열고 아래 명령어를 입력해 주세요.

pip install -r requirements.txt


2. 웹 대시보드 실행

설치가 완료되면 동일한 터미널 창에서 아래 명령어를 실행하여 웹페이지를 엽니다.

streamlit run app.py


명령어 실행 후 자동으로 브라우저가 열리며, 왼쪽 사이드바에서 campus_life.csv 파일을 업로드하면 즉시 분석 결과를 확인할 수 있습니다.
